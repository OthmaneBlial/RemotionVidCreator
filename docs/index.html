One opinionated path

Control the decisions that change the cut.

This is not another timeline editor or rendering cloud. It is a focused first-success workflow on top of Remotion: structured input, inspectable creative direction, and an output you can reproduce.

Write the brief

Start with the idea, goal, audience, platform, pace, and duration. A useful template fallback works without an AI key.

Shape the direction

Choose narrative, style, intensity, motion, density, and imagery. Use bundled photos or opt into compliant Unsplash sourcing.

scene plan → visuals → audio bed

Render locally

The Python queue tracks the job while the TypeScript worker bundles the composition and writes an H.264 MP4 to your local output folder.

Clear boundaries

Know what stays local.

Rendering, job history, and output stay on your machine. Optional providers receive only the prompt or image query needed for the path you enable.

Runs on your machine

  • Browser workspace and Python job queue
  • Bundled offline image selection
  • Procedural ambient audio generation
  • Remotion bundle, render, history, and MP4 output

Optional network paths

  • Z.ai receives the topic and brief when configured
  • Unsplash receives image searches when online visuals are selected
  • The classic CLI can fetch Wikipedia context and Picsum images
  • Remote fonts or image URLs may be fetched during a selected render
